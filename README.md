# Indian Hearing Care Clinic Management

A responsive clinic operations prototype for an audiology and speech therapy centre.

## Included
- Daily appointment overview and schedule
- Patient directory with care tracks and balances
- Speech therapy attendance register with package session balances
- Billing for hearing aids, hearing tests, and speech therapy
- Receivables, service/rate list, report summaries, and CSV export

## Run
Open `index.html` in a modern browser. No build step is required.

## Prototype data
All patient names, schedule entries, balances, metrics, and rates are sample data. New patient records, invoices, and attendance changes are saved in this browser's local storage. They are not shared across devices or users.

Before clinic use, replace sample rates with the clinic's approved fee schedule and connect secure server-side storage, authentication, backups, and appropriate access controls. This prototype is not a production medical-record system.

Clinic context: Indian Hearing Care & Research Centre, Patiala.
